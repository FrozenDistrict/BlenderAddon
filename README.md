# HF2 Blender Addon
This is an official addon made by Frozen District to help you create modded content for House Flipper 2. To use it, you have to download Blender, which you can find here: https://www.blender.org/download/
# Download
https://github.com/FrozenDistrict/BlenderAddon/releases/
# Installation
1. Check the releases tab, and download the latest version
2. Open Blender
3. Go to **Edit → Preferences → Add-ons**
4. Click the dropdown menu and select **Install from Disk**
5. Navigate to where you saved the addon ZIP file
6. Select the file and click **Install Add-on**
7. After installation, check the box next to the addon name to enable it
8. Expand the addon settings by clicking the arrow
9. Click the **Install Pillow** button (this is required for alpha channel manipulation)
# Usage
To access the addon screen, in the 3D viewport, press **N** to open the side panel, and click on the **HF2** tab.
